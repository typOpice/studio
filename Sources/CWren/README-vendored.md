# Vendored Wren

Wren 0.4.0 (https://wren.io), MIT licensed — see `LICENSE-wren.txt`. The VM and the
optional `meta` and `random` modules, copied verbatim and flattened so SwiftPM can
build them as a plain C target. Nothing here is modified.

Wren is the secondary scripting language; Luau (Sources/CLuau) is primary.
